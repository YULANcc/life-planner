# 生活规划台

给低精力人群用的生活规划工具。三个界面：**规划台**（定目标、拆任务）→ **本周**（半天粒度排期、一巴掌打卡）→ **复盘**（周图 + 规则洞察）。

设计前提：低精力人群缺的不是时间，是电。所以约束轴是**精力预算**，不是时间预算；每个任务都配一个"简版"，没电时降级做完也算完成。

## 怎么打开

直接双击 `index.html`，用浏览器打开即可。不需要装任何东西、不需要联网、不需要账号。

数据全部存在你自己浏览器里（localStorage），不上传、不联云，所以隐私边界是干净的。

想换台设备或备份：点右上角「导出」存一个 JSON，「导入」还原。

## 三个界面

| 界面 | 干什么 |
|---|---|
| 规划台 | 建目标（带类型：学习型/探索型/体验型，可自定义）、把目标拆成可重复的任务，每个任务配「完整版」和「简版」两套时长与精力 |
| 本周 | 周一到周日 × 早/午/晚 的网格。点「生成本周排期」按任务的重复规则自动铺满一周；每张卡三个按钮：完成 / 一半 / 跳过。右上角「今天没电」会把今天剩下的全部降级成简版 |
| 复盘 | 完成率、类型配比、各目标推进、每日完成、时段完成率、精力收支，外加几句规则生成的观察。每周翻页看历史 |

精力预算默认早 3 / 午 3 / 晚 2，可在「设置」里改。超出预算的时段会标黄。

## 部署（可选）

目录本身就是纯静态站点，没有任何构建步骤。

- **Cloudflare Pages**：新建项目 → 直接上传这个目录（或连 Git 仓库），框架预设选 None，构建命令留空，输出目录填 `/`。
- **GitHub Pages**：把目录推到仓库，Settings → Pages → 选分支根目录。

部署后是 https 链接，手机上「添加到主屏幕」会当成 PWA 打开（manifest 和图标已配好）。

## 视觉取向

明亮、克制。层级靠底色深浅和 1px 分栏线表达，不靠卡片堆叠和阴影，所以周表、复盘数据行用的是同一套分栏语言。全站只有一个强调色（靛紫 `#5B4EE9`），只出现在进度、选中和焦点上；主按钮用墨色而不是彩色。阴影只留给弹窗。

三个类型色（学习 `#4C6EF5` / 探索 `#0FA68C` / 体验 `#E8813F`）是数据编码，只用在任务左侧细标记和配比图上。

字体用系统无衬线栈，不引入第二套字体；数字列统一 `tabular-nums` 对齐。改了主色或类型色的话，记得同步 `styles.css` 的变量和 `app.js` 里的 `TYPE_COLORS`、`CHART`。

## 自检

URL 参数：

- `?selftest=1` 把关键布局尺寸和一次模拟打卡的结果写进页面底部，用于改动后的回归检查
- `?seed=1` 载入示例数据（4 个目标 + 5 个任务，含上周模拟打卡），空库时看效果用
- `?reset=1` 清空所有数据
- `?tab=plan|week|review` 直接打开某个视图

`shots/driver.html` 是一个端到端驱动页，用 iframe 模拟真实操作路径（新建目标 → 拆任务 → 选重复日 → 生成排期 → 打卡），跑完把每一步结果打到页面上，用来验证功能没坏。
